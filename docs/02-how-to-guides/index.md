# How-To Guides (EN)

Operational runbooks written in strict ASD-STE100 Issue 9 for `expenseapp` container deploy, user administration, and data export tasks.

- [Deploy and Configure the Container](01-deploy-and-configure-container.md): Build and launch `expenseapp` with safe credentials and persistent storage.
- [Manage Users, Groups, and Approvals](02-manage-users-groups-and-approvals.md): Create users, assign group roles, and approve submitted reports.
- [Export Reports and Back Up SQLite](03-export-reports-and-backup-sqlite.md): Download CSV, JSON, and YAML exports and back up `expense.db` safely.
