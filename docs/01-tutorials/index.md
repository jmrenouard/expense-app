# Tutorials (EN)

Follow these step-by-step learning exercises against a local `expenseapp` instance.

- [Quickstart with Docker and Local Go Runtime](01-quickstart-docker-and-local-run.md): Build and launch `expenseapp` with Make/Docker or standalone `go run .` and authenticate via `/api/auth/login`.
- [Expense Report Lifecycle Lab](02-expense-report-lifecycle-lab.md): Create a draft report, attach itemized VAT expenses and a receipt, submit, approve, and export CSV/JSON/YAML.
